# dotfiles

## Git

Commit minor changes straight to `main` and push: config tweaks, aliases, comments, docs, changelog entries, adding a tool or a package to mise. Open a PR for anything that can break a machine or every session on it: `setup-macos`, `setup-linux`, the bootstrap task and hooks in `config.d/mise`, Claude hooks and settings, and changes that move, link or delete files in `$HOME`, which includes `[dotfiles]` entries.
