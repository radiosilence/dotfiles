# Herdr app key migration

The herdr TUI ran inside Ghostty, which keeps every `cmd` shortcut for itself, so its bindings went on a `ctrl-a` prefix and on `alt`. The Herdr app is its own window and binds `cmd` directly. `config.d/herdr-app/keys.json` is therefore the app's default keymap plus the four bindings it has no default for; everything else uses the default.

`ctrl-a` no longer belongs to Herdr, so it is beginning-of-line again in zsh and readline. `ctrl-t` (fzf file widget) and `alt-n`, `alt-o`, `alt-[`, `alt-]` also go back to the terminal.

## Old key to new key

| Action | herdr TUI | Herdr app |
|---|---|---|
| Focus pane left/down/up/right | `ctrl-a h/j/k/l` | `cmd-alt-arrow` |
| Swap pane | `ctrl-a alt-h/j/k/l` | `cmd-alt-shift-arrow` |
| Split right / down | `alt-n` / `alt-shift-n` | `cmd-d` / `cmd-shift-d` |
| Zoom pane | none | `cmd-shift-enter` |
| Close pane | `ctrl-a x` | `cmd-shift-w` |
| New tab | `ctrl-t` | `cmd-t` |
| Close tab | `ctrl-w` | `cmd-w` |
| Next / previous tab | `ctrl-tab` / `ctrl-shift-tab` | unchanged, or `cmd-shift-]` / `cmd-shift-[` |
| Go to tab N | `ctrl-a 1..9` | `cmd-1..9` |
| Rename tab | `ctrl-a r` | `f2` |
| New space (workspace) | `ctrl-a n`, `alt-shift-o` | `cmd-n` |
| Close space | `ctrl-a shift-x` | `cmd-alt-w` |
| Rename space | `ctrl-a shift-w` | `shift-f2` |
| Go to space N | `alt-shift-1..9` | `ctrl-1..9` |
| Next / previous space | `alt-]` / `alt-[` | `cmd-alt-]` / `cmd-alt-[` |
| Space and tab picker | `ctrl-a w`, `alt-o` | `cmd-p` |
| Next / previous agent | `ctrl-a tab` / `ctrl-a shift-tab` | `cmd-]` / `cmd-[` |
| Toggle sidebar | `ctrl-a s` | `cmd-b` |
| Help | `ctrl-a ?` | `cmd-/` |
| Settings | `ctrl-a ,` | `cmd-,` |
| Command palette | none | `cmd-shift-p` |
| Scratch shell popup | `ctrl-a ;` | `cmd-;` |
| PR or issue to worktree popup | `alt-shift-p` | unchanged |
| Worktree picker popup | `alt-w` | unchanged |

The popups are the `popup-*` mods in `config.d/herdr-app/mods`. The command palette is generated by the app and cannot list them, so they are reachable only by key.

## Gone

These TUI actions have no app command: navigate mode, cycling panes, renaming panes, focusing agent N, native worktree actions, detach (closing the window leaves terminals running), reloading config (files apply on save), copy mode, scrollback editing, goto and jumping to a notification's target.
