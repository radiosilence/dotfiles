# Herdr app key migration

The herdr TUI ran inside Ghostty, which keeps every `cmd` shortcut for itself, so its bindings went on a `ctrl-a` prefix and on `alt`. The Herdr app is its own window and binds `cmd` directly. `config.d/herdr-app/keys.json` is therefore the app's default keymap plus the bindings it has no default for; everything else uses the default.

`ctrl-a` no longer belongs to Herdr, so it is beginning-of-line again in zsh and readline. `ctrl-t` (fzf file widget) and `alt-n`, `alt-o`, `alt-[`, `alt-]` also go back to the terminal.

## Old key to new key

| Action | herdr TUI | Herdr app |
|---|---|---|
| Focus pane left/down/up/right | `ctrl-a h/j/k/l` | `cmd-alt-arrow` |
| Swap pane | `ctrl-a alt-h/j/k/l` | `cmd-alt-shift-arrow` |
| Split right / down | `alt-n` / `alt-shift-n` | `cmd-d` / `cmd-shift-d` |
| Zoom pane | none | `cmd-shift-enter` |
| Close pane | `ctrl-a x` | `cmd-shift-w` |
| New tab | `ctrl-t` | `cmd-t` |
| Close tab | `ctrl-w` | `cmd-w` |
| Next / previous tab | `ctrl-tab` / `ctrl-shift-tab` | unchanged, or `cmd-shift-]` / `cmd-shift-[` |
| Go to tab N | `ctrl-a 1..9` | `cmd-1..9` |
| Rename tab | `ctrl-a r` | `f2` |
| New space (workspace) | `ctrl-a n`, `alt-shift-o` | `cmd-n` |
| New space in a folder picked with zoxide | none | `cmd-shift-n` |
| Close space | `ctrl-a shift-x` | `cmd-alt-w` |
| Rename space | `ctrl-a shift-w` | `shift-f2` |
| Go to space N | `alt-shift-1..9` | `ctrl-1..9` |
| Next / previous space, worktrees included | `alt-]` / `alt-[` | `cmd-]` / `cmd-[` |
| Space and tab picker | `ctrl-a w`, `alt-o` | `cmd-p` |
| Next / previous agent | `ctrl-a tab` / `ctrl-a shift-tab` | unbound |
| Toggle sidebar | `ctrl-a s` | `cmd-b` |
| Help | `ctrl-a ?` | `cmd-/` |
| Settings | `ctrl-a ,` | `cmd-,` |
| Command palette | none | `cmd-shift-p` |
| Scratch shell popup | `ctrl-a ;` | `cmd-;` |
| Grove: pull requests | `alt-shift-p` | unchanged |
| Grove: issues | none | `alt-shift-i` |
| Grove: worktrees | `alt-w` | unchanged |
| GitHub board ([gh-board](gh-board.md)) | none | `cmd-shift-g` |

`cmd-[` and `cmd-]` replace the default agent bindings. They run grove's `grove-prev` and `grove-next` mods, which step through spaces in the order the sidebar shows them, with each worktree's space directly after its main checkout's. The built-in `space.next` (`cmd-alt-]`) follows creation order, which skips about once worktrees are nested.

The popups, the zoxide folder picker and the space stepping are [grove](https://github.com/radiosilence/grove)'s mods, which `task link` clones to `~/.local/share/grove` and copies into `~/.config/herdr-app/mods`. The command palette is generated by the app and cannot list them, so they are reachable only by key.

## Usage bar

`layouts/main-usage.json` is a clone of the shipped `main` layout with [herdr-usage-bar](https://github.com/berkeatac/herdr-usage-bar) (vendored at `422ae65` in `mods/usage-bar`) left of the status bar. It is a clone because shipped layouts are overwritten on update. The mod's helper reads provider logins and calls their usage endpoints every two minutes.

Two local changes: Claude is the only provider shown by default, and `collect.py` reads the Keychain item Claude Code uses when `CLAUDE_CONFIG_DIR` is set (`Claude Code-credentials-<first 8 hex of sha256(dir)>`); upstream skips Keychain entirely in that case. The first read is denied until **Retry Keychain** in the Claude popup is clicked and macOS is told to always allow it. Reapply both changes when updating the vendored copy.

## Gone

These TUI actions have no app command: navigate mode, cycling panes, renaming panes, focusing agent N, native worktree actions, detach (closing the window leaves terminals running), reloading config (files apply on save), copy mode, scrollback editing, goto and jumping to a notification's target.
